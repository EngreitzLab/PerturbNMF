# TASK

Propose up to the requested number of hypotheses, ranked best first. Rank by interest (would the result change how this cell type is understood?), support (how many findings, programs and consistent regulator signs back it) and tractability (can one experiment test it?). Keep the list diverse: at most two hypotheses about the same regulator or the same program.

Each hypothesis:
- title: at most 12 words, naming the regulator(s) or program(s) and the mechanism.
- claim: 1-3 sentences, the mechanistic claim, with direction.
- programs: the program ids it is about (e.g. P10).
- regulators: the perturbed regulators it is about, as named (may be empty).
- finding_ids: the findings it rests on, at least one.
- rationale: 1-3 sentences on why the data support it, citing the regulator signs and findings.
- experiment: one concrete experiment that would test it, with the expected result if the hypothesis is right.
- confidence: high, medium or low.
- caveat: the main reason it could be wrong.
